Stream your 3DS screens to a browser on the same Wi-Fi, no PC software needed.

## Install

1. In **FBI**, choose **Remote Install → Scan QR Code** and scan:

   ![Install QR code](https://raw.githubusercontent.com/AllPawsonDeck/3DSLink/main/docs/install-qr.png)

   (Or copy `3DSLink.cia` to the SD card and install it with FBI.)
2. Open **3DSLink** from the HOME Menu. The first launch installs the streaming service.
3. Open the address shown on the top screen in Chrome on your computer.

You only need `3DSLink.cia`. `3DSLinkService.cia` is the same service on its own, for advanced users.
