# 3DSLink

3DSLink is an experimental browser-first screen streamer for modded Nintendo 3DS systems, with Old 3DS / Old 3DS XL as the first target.

Goal:

```text
3DS -> Wi-Fi -> browser -> Discord screen share
```

No Java receiver, no Linux desktop app, and no special viewer software on the Chromebook.

## Planned v0.1

- Background capture based on the proven HzMod / ChirunoMod approach
- Old 3DS-friendly strip capture to keep memory use down
- Top + bottom screen streaming over local Wi-Fi
- Browser viewer served directly by the 3DS
- 3DS-style, clean dual-screen, and top-only layouts
- Pop-out views with no controls inside the pop-out window
- Adjustable JPEG quality / frame pacing
- Start + Select emergency stop
- No audio in v0.1

## Status

Very early development. Do not install test CIAs unless a release explicitly says they are ready for hardware testing.
